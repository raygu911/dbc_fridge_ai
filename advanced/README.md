# FridgeAI Advanced Training

The advanced track extends the completed four-session MVP with techniques used in larger and more demanding AI systems. Each topic will become a standalone learning module with its own code, tests, evaluation criteria, and architecture notes.

## Planned Modules

| Module | Goal | Status |
| --- | --- | --- |
| [Hybrid retrieval](hybrid-retrieval/) | Combine semantic and lexical search | Planned |
| [Reranking](reranking/) | Improve result ordering with a second-stage model | Planned |
| [Evaluation](evaluation/) | Measure retrieval and generation quality | Planned |
| [Observability](observability/) | Trace, log, and monitor the RAG pipeline | Planned |
| [Cloud deployment](cloud-deployment/) | Deploy and operate FridgeAI in managed infrastructure | Planned |

Advanced modules should be completed after the base track. They may introduce additional infrastructure, datasets, model downloads, and operating costs.
